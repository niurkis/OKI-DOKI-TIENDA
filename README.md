# Oki Doki - Tienda de Calzado en Cuero

E-commerce de calzado y accesorios de cuero.

## Requisitos

- Node.js v18+
- MySQL 8+

## Instalación

1. Clonar el repositorio:
   ```
   git clone <https://github.com/niurkis/OKI-DOKI-TIENDA.git>
   cd OKI-DOKI-TIENDA
   ```

2. Instalar dependencias:
   ```
   npm install
   ```

3. Configurar la base de datos MySQL:
   - Crear la base de datos usando el archivo `database.sql`:
     ```
     mysql -u root -p < database.sql
     ```
   - Ajustar credenciales en la conexión si es necesario.

4. Iniciar el servidor:
   ```
   npm start
   ```

5. Abrir en el navegador:
   ```
   http://localhost:3000
   ```
